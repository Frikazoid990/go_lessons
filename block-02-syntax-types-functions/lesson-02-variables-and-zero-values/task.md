## Questions

1. Чем `var level = 6` отличается от `level = 6`?
2. Почему повторный `level := 9` в том же блоке вызывает ошибку, а объявление с существующим и новым именами может быть допустимо?

## 1. Наблюдаем zero values

Объяви без начальных значений пять переменных:

- `attempts` — `int`;
- `smallCount` — `int32`;
- `ratio` — `float64`;
- `enabled` — `bool`;
- `title` — `string`.

Выведи имя, тип и значение каждой. Строку выводи через `%q`.

Затем через `=` присвой каждой непустое или ненулевое значение и снова выведи все пять. После этого верни `enabled` и `title` к их zero values явными присваиваниями.

**Проверка:** видны три этапа; значения меняются, типы сохраняются, пустая строка различима.

## 2. Четыре способа объявления

Объяви четыре разные переменные с одинаковым целым значением `12`:

1. Через `var` с явными типом и значением.
2. Через `var` с выводом типа.
3. Через `:=`.
4. Через `var` без начального значения, затем отдельное присваивание.

Выведи тип и значение каждой.

**Вариация:** добавь переменные, объявленные через `:=` со значениями `12.0`, `"12"` и `false`. Перед запуском запиши прогноз их типов в комментариях.

**Проверка:** сам напиши все формы и сопоставь прогноз с `%T`.

## 3. Сохраняем текущее значение

- Объяви `currentID` со значением `31`.
- Объяви `savedID`, получив значение из `currentID`.
- Выведи обе.
- Измени только `currentID` на `47`, снова выведи обе.
- Присвой `savedID` текущее значение `currentID`, снова выведи обе.
- Измени только `savedID` на `90`, выведи обе.

**Вариация:** повтори ту же последовательность с двумя строковыми переменными и двумя разными словами.

**Проверка:** вывод показывает результат каждого присваивания; в одном комментарии объясни, почему переменные не меняются вместе автоматически.

## 4. Несколько имён и повторное использование

- Одной строкой с `:=` объяви `primary` и `secondary` со значениями `10` и `20`.
- Одной строкой через `=` измени обе на `30` и `40`.
- Одной строкой с `:=` используй существующую `primary` и объяви новую строковую переменную `stage`. Задай им значения `50` и `"ready"`.
- Выведи все три переменные.
- Ещё одной строкой через `=` измени `primary` и `stage`.

**Проверка:** после каждого этапа есть вывод; в комментарии к третьему шагу укажи, какое имя делает `:=` допустимым.

## 5. Получаем и исправляем ошибки

По очереди добавляй каждый фрагмент в `main`. После него добавь вывод переменных. Запускай программу, записывай основную диагностику, затем исправляй и запускай снова. В итоговом файле оставь исправленный вариант и короткий комментарий о причине ошибки.

Первый фрагмент:

```go
retries := 2
retries := 5
```

Второй:

```go
var description
description = "draft"
```

Третий:

```go
var narrow int32 = 7
ordinary := 7
ordinary = narrow
```

В третьем случае исправь **объявление `ordinary`**, согласовав типы. Преобразования оставляем для 2.3. Добавь комментарий: сколько бит и байтов задаёт `int32`, и почему `%T` не измеряет размер памяти.

**Проверка:** для каждой ошибки есть твоя диагностика, объяснение причины и работающий исправленный код.
