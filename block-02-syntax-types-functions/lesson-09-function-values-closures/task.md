# Lesson 2.9 — Function Values and Closures

## Счётчики обработки

Цель: использовать функцию как значение и проследить состояние замыкания. Код пиши в `main.go` этого проекта; модуль — `lesson-09-function-values-closures`.

1. Создай именованную функцию с типом `func(int) int`, увеличивающую входное число на 1, и функцию, принимающую число и функцию этого типа и вызывающую её для числа. В `main` сохрани именованную функцию в переменной и передай её в вызывающую функцию. Затем присвой той же переменной анонимную функцию того же типа, удваивающую число, и повтори вызов с числом 3. До запуска запиши прогноз обоих результатов.
2. Создай функцию, принимающую начальное число и возвращающую `func() int`: возвращённое замыкание увеличивает собственный счётчик на 1 и возвращает его. Создай два счётчика с начальными значениями 0 и 10; вызови первый два раза, второй один раз, затем скопируй значение первого в другую переменную и вызови копию. До запуска запиши прогноз всех результатов и объясни, какие вызовы используют общую переменную счётчика.
3. Сравни прогноз с фактическим выводом. Используй `fmt`, числа, функции и изученные конструкции; без коллекций, горутин, тестов и захвата переменных цикла.

Критерий: программа демонстрирует передачу и вызов функции, замену значения функции, независимость двух счётчиков и общее состояние копии первого; прогноз сопоставлен с выводом.

Пришли ответы на вопросы урока, прогноз и фактический вывод, сохранив код в `main.go` для проверки:

1. Чем отличается передача `operation` от вызова `operation(3)`?
2. Когда исполняется тело анонимной функции?
3. Почему два вызова создающей функции дают независимые счётчики, а копия одного замыкания разделяет состояние?
