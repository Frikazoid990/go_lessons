# Lesson 2.9 — Function Values and Closures

## Счётчики обработки

Цель: использовать функцию как значение и проследить состояние замыкания. Код пиши в `main.go` этого проекта; модуль — `lesson-09-function-values-closures`.

1. **Функция как значение.** Объяви функцию `increment(n int) int`: она принимает число `n` типа `int` и возвращает `n + 1`. Затем объяви функцию `apply`, которая принимает число и функцию типа `func(int) int`, вызывает эту переданную функцию для числа и возвращает полученный результат. Запись `func(int) int` здесь означает: один параметр типа `int`, один результат типа `int`.

   В `main` присвой `increment` переменной `operation` без скобок — так в переменную попадёт сама функция, вызова пока не будет. Передай `operation` в `apply` с числом 3 и запиши прогноз результата. Затем присвой `operation` анонимную функцию с тем же типом, которая умножает число на 2; снова вызови `apply` с числом 3 и запиши прогноз. После этого выведи оба результата через `fmt.Println`.

2. **Замыкание со счётчиком.** Объяви функцию `makeCounter(start int) func() int`. Она принимает начальное значение счётчика и возвращает функцию без параметров, которая возвращает `int`. Внутри `makeCounter` создай переменную `count` со значением `start`. Возвращаемая анонимная функция при каждом вызове должна увеличить `count` на 1 и вернуть новое значение.

   В `main` создай `first` вызовом `makeCounter(0)` и `second` вызовом `makeCounter(10)`. Запиши прогноз и выведи результаты в таком порядке: вызови `first` два раза, `second` один раз, присвой `first` переменной `copyFirst` и вызови `copyFirst` один раз. Объясни, какие вызовы меняют один и тот же `count`, а какие — разные.

3. Сравни прогноз с фактическим выводом. Используй `fmt`, числа, функции и изученные конструкции; без коллекций, горутин, тестов и захвата переменных цикла.

Критерий: программа демонстрирует передачу и вызов функции, замену значения функции, независимость двух счётчиков и общее состояние копии первого; прогноз сопоставлен с выводом.

Пришли ответы на вопросы урока, прогноз и фактический вывод, сохранив код в `main.go` для проверки:

1. Чем отличается передача `operation` от вызова `operation(3)`?
2. Когда исполняется тело анонимной функции?
3. Почему два вызова создающей функции дают независимые счётчики, а копия одного замыкания разделяет состояние?
