# Lesson 2.8 — Scope and Shadowing

## Scope Lab — лимит обработки

Цель: самостоятельно показать разницу между затенением переменной и изменением внешней переменной, а также границы имён в цикле.

Код пиши в `main.go` этого проекта. Модуль уже создан: `lesson-08-scope-shadowing`.

1. В `main` объяви базовый `limit` со значением `10` и выведи его. В `if` для специального режима намеренно объяви новую переменную `limit` со значением `4` и выведи её. После `if` выведи базовый лимит. До запуска предскажи вывод.
2. Добавь вторую условную ветку, которая при изменении режима действительно меняет внешний лимит через `=`. Выведи итоговый лимит. Покажи работу обоих режимов, изменяя входное значение режима.
3. В одной из веток используй `:=` с двумя именами: первое совпадает с именем внешнего лимита, второе новое в этой ветке. Используй оба значения и покажи лимит после ветки. Объясни, какую переменную изменило объявление.
4. Добавь цикл обработки чисел от `1` до итогового лимита включительно. Подсчитывай обработанные значения в переменной, объявленной вне цикла, и выведи счётчик после него. Объясни границы имени переменной счётчика цикла.

Используй знакомые числа, строки, `if`, обычный `for` и `fmt`; без коллекций, замыканий и обработки ошибок. Не оставляй некорректные строки в конечном коде.

Критерий: программа работает для обоих режимов, показывает отличие затенения от присваивания, прогноз сравнен с выводом, объяснены области видимости имён и правило `:=`.

Пришли прогноз и фактический вывод обоих режимов, сохранив код в `main.go` для проверки.

Вопросы урока уже обсуждены и закрыты; их можно использовать для повторения:

1. Что произойдёт с внешним `limit` при `limit := 4` и при `limit = 4` внутри `if`, если внутреннего `limit` до этого нет?
2. Почему `limit, extra := 4, 2` во вложенном блоке и в том же блоке, где объявлен `limit`, дают разный результат?
3. Где доступны переменные, объявленные в начальной инструкции `if` и `for`?
