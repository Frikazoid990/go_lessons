## 1. Division Lab — деление и преобразования

Объяви целые переменные `a = 19`, `b = 4`. Выведи:

- сумму, разность и произведение;
- целое частное и остаток;
- дробное частное: преобразуй оба числа в `float64` **до деления**;
- результат преобразования в `float64` **после целочисленного деления**.

Для двух последних результатов выведи также тип через `%T`.

Затем поменяй `a` на `-19`, оставь `b = 4` и повтори запуск. Объясни знак остатка и разницу между двумя способами преобразования.

## 2. Capacity Check — вместимость

Есть три целые переменные:

```text
current = 9
incoming = 3
capacity = 12
```

`current` — сколько уже занято, `incoming` — сколько поступает, `capacity` — максимальная вместимость.

Вычисли будущий размер и три отдельных значения `bool`:

- всё поступление помещается, включая точное заполнение до предела;
- будущий размер равен пределу;
- после поступления останется свободное место.

Выведи логические результаты через `%t`. Проверь три варианта `incoming`: `2`, `3`, `4`.

## 3. Access Rule — правило доступа

Объяви четыре переменные типа `bool`:

- `active` — аккаунт активен;
- `paid` — подписка оплачена;
- `trial` — есть пробный доступ;
- `blocked` — аккаунт заблокирован.

Самостоятельно составь выражение для `allowed` по правилу:

> Доступ разрешён, когда аккаунт активен, есть оплаченная подписка или пробный доступ, а блокировки нет.

Проверь все пять наборов:

| `active` | `paid` | `trial` | `blocked` |
|---|---|---|---|
| `true` | `false` | `true` | `false` |
| `true` | `false` | `false` | `false` |
| `false` | `true` | `false` | `false` |
| `true` | `true` | `false` | `true` |
| `true` | `true` | `false` | `false` |

Отдельно сравни два выражения:

```go
active && paid || trial
active && (paid || trial)
```

Для этого возьми `active=false`, `paid=false`, `trial=true`. Предскажи результаты, проверь и объясни влияние скобок. Это отдельный эксперимент с группировкой.

## 4. Safe Divisibility — безопасная проверка делимости

Объяви целые `total = 24`, `divisor = 0`.

Самостоятельно составь выражение для `divisible`:

> Делитель ненулевой **И** число `total` делится на него без остатка.

Проверь `divisor`: `0`, `5`, `6`. Для каждого варианта перед запуском запиши:

- ожидаемое значение `divisible`;
- будет ли вычисляться правая часть `&&`.

Программа должна успешно завершаться во всех трёх случаях. Отдельно деление на ноль не запускай.
