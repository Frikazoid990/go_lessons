### Lesson 3.2 — Seat Counter Update

**Цель:** получить адрес переменной типа `int`, прочитать число через копию указателя и изменить исходное число из функции с параметром `*int`.

**Проект:** `go_lessons/block-03-values-pointers-structs/lesson-02-addresses-and-pointers`, модуль `lesson-02-addresses-and-pointers`. Папку урока и `main.go` создаёт пользователь. В папке урока команда `go mod init lesson-02-addresses-and-pointers` создаст `go.mod`. После появления начальных файлов сохранить условие в `task.md` рядом с кодом.

**Вопросы до практики**

1. Даны `count := 8`, `p := &count` и `q := p`. Что хранит каждая переменная? Что прочитают `count` и `*p` после записи `*q = 11`?
2. Параметр `target *int` получил значение указателя из вызывающего кода. Чем отличаются записи `target = other` и `*target = 7`, если `other` — указатель на другую переменную типа `int`? Рассмотри строки по отдельности.

**Задание**

1. В `main` объяви `freeSeats` со значением 24. Это число свободных мест в зале. Сохрани исходное число в отдельной переменной `before`. Получи адрес `freeSeats` в переменную `counter` и скопируй указатель из `counter` в `display`.
2. На уровне пакета объяви функцию с именем `book` и двумя параметрами. Первый параметр `target` имеет тип указатель на `int` и указывает на счётчик свободных мест. Второй параметр `seats` имеет тип `int` и задаёт число бронируемых мест. Функция уменьшает число свободных мест по адресу из `target` на `seats` и завершается без возвращаемого значения. При вызове передай `counter` и 5. Для этого примера мест достаточно.
3. После вызова выведи эти три строки в таком формате:

   ```text
   До бронирования: 24
   Свободно сейчас: 19
   На табло: 19
   ```

   Вместо чисел в примере подставь значения из переменных `before`, `freeSeats` и `display` соответственно. Запусти `go run .` из папки урока.

**Ограничения:** используй `int`, `*int`, присваивания, именованную функцию и `fmt`. Для входов задания проверки, `nil`, структуры, коллекции и тесты не нужны.

**Критерий:** после вызова исходная копия числа равна 24, а значение, прочитанное напрямую из `freeSeats` и через `display`, равно 19. По коду и объяснению видно, что скопировалось в параметр и куда функция записала число.

**Что прислать:** ответы на два вопроса, путь к `main.go` или сам код, фактический вывод `go run .` и короткое объяснение, почему `display` показывает новое число.
