# Lesson 3.1 — Copying Values

## Request Limit Preview

**Цель:** показать независимость копии `int`, локальность изменения параметра и явное сохранение возвращённого значения.

**Проект:** `go_lessons/block-03-values-pointers-structs/lesson-01-value-copy`; модуль `lesson-01-value-copy`.

**Вопросы до практики:**
1. После `a := 8; b := a; a = 13; b++` какие значения у `a` и `b` и почему?
2. Функция `calculate(value int) int` меняет параметр и возвращает его. Чем отличается вызов `calculate(limit)` от `limit = calculate(limit)` в вызывающей функции?

**Задание:** напиши в `main.go` программу о расчёте лимита запросов. Переменная `limit` содержит число разрешённых запросов. Параметр `amount` задаёт число, которое нужно вычесть из переданного лимита. Функция `reserve` возвращает рассчитанный лимит. Эта задача не моделирует деньги или бронирование ресурсов.

1. В `main` объяви `limit := 60`. Скопируй его значение в новую переменную `snapshot`. Затем присвой `limit` значение 45. Выведи обе переменные с поясняющим текстом `current limit:` и `saved limit:`.
2. Вне `main`, на уровне пакета, объяви `func reserve(limit int, amount int) int`. Параметр `limit` получает копию числа из первого аргумента. Параметр `amount` получает число из второго аргумента. В теле функции вычти `amount` из параметра `limit`. Выведи новое число командой `fmt.Println("inside:", limit)` и верни его через `return`. Строка `"inside:"` — текст, который появится перед числом в консоли. Это не переменная и не Go label.
3. Вызови `reserve(limit, 12)` и не сохраняй возвращённое число. Затем выведи `limit` и `snapshot`, добавив перед ними поясняющий текст `after ignored call — limit:` и `after ignored call — snapshot:`.
4. Снова вызови `reserve(limit, 12)`, сохранив возвращённое число в новой переменной `proposed`. Выведи `limit`, `snapshot` и `proposed` с пояснениями `after preview — limit:`, `after preview — snapshot:` и `after preview — proposed:`.
5. Присвой значение `proposed` переменной `limit`. Затем увеличь `proposed` на единицу. Выведи `limit` и `proposed` с пояснениями `after assignment — limit:` и `after increment — proposed:`.

В обоих вызовах передай вторым аргументом число 12. Начальные значения обеспечивают условие `0 <= amount <= limit`, поэтому проверку и обработку отказа писать не требуется.

Запусти программу командой `go run .` из папки проекта и проверь, что вывод соответствует выполненным шагам.

**Ограничения:** достаточно `int`, присваиваний, именованной функции и `fmt`. Без указателей, структур, коллекций, замыканий, глобального изменяемого состояния и тестов. Не заменять передачу параметра обращением к внешней переменной.

**Критерий:** по коду и выводу можно определить, что параметр меняется внутри `reserve`, вызов без сохранения результата не изменил `limit` в `main`, а явное присваивание результата изменило его. `snapshot` сохраняет число, которое было в `limit` на момент копирования.

**Что прислать:** ответы на два вопроса, код из `main.go`, фактический вывод и короткое объяснение, какая переменная меняется на каждом шаге.
